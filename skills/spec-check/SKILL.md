# /spec-check — 정본 대조

규칙은 `AGENTS.md`를 따른다. 결과는 PR 코멘트용 리포트이며 병합 여부는 리뷰어가 정한다.

## 1. 기준 읽기
대상 화면의 요약본과 `canon_index.md`가 가리키는 정본 절, 그 화면이 쓰는 계약 operation, Figma URL이 있으면 시안(디자인 부록을 켠 팀은 Figma MCP), 해당 코드와 테스트.

## 2. 판정 (항목마다 하나)

| 판정 | 뜻 | 조치 |
| :---: | :--- | :--- |
| ✅ 일치 | 정본 · 계약 · 시안과 코드가 맞음 | 없음 |
| ❌ 위반 · 누락 | 정본의 필드 · 계산식 · 상태 · POL 규칙이 없거나 다름, 시안의 필수 요소가 빠짐 | 개발자 수정 |
| ⚠️ 임의 구현 | 정본 · 계약에 없는 규칙이 질문 없이 들어감, 시안 구조를 임의로 바꿈 | 제거하거나 질문 Issue |
| 🟡 가정 진행 | `[ASSUMPTION: Q-ID]`로 진행 중 | 릴리스 전 정리 |
| ❓ 미정의 | Blocking 질문으로 멈춘 상태 | 도메인 담당자 답 대기 |

`hotfix` 라벨 PR이면 리포트 머리에 "핫픽스: 사후 동기화 필요"를 단다.
