# AI 에이전틱 시스템 구축 규약

AI를 쓰는 업무 환경(PO/PM · UIX 디자이너 · FE/BE 개발자 · 코딩 에이전트)에서 정본과 코드를 하나의 흐름으로 맞추는 규약 문서 모음.

| 파일 | 누가 · 언제 |
| :--- | :--- |
| `AI_에이전틱_핵심규약.md` | 모든 AI가 매일. 저장소에 `AGENTS.md`로 설치 |
| `AI_에이전틱_프로젝트_설치서.md` | 세팅 담당이 프로젝트를 추가할 때 한 번 (설정 질문 12개 포함) |
| `AI_에이전틱_합류_안내.md` | 새로 합류한 사람이 처음 한 번 |
| `skills/` | 스킬 5종 원문(`SKILL.md`), 설치 때 각 저장소 `.claude/skills/`로 복사 |
| `AI_에이전틱_선택_부록.md` | 디자인 시스템 · 계약 테스트 · 계산기 · 메신저 알림 (켠 팀만) |
| `AI_에이전틱_환경_가이드.html` | 사람 브리핑용 시각 가이드 |
| `AI_에이전틱_검토로그.md` | 검토 지적과 결정 기록 |

가이드는 GitHub Pages에서 열면 MD 다운로드 링크가 함께 동작한다.
